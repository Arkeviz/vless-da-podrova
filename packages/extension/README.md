# @vdp/extension

WXT + Vue 3 + TypeScript. Структура по FEOD:

```
src/
  app/        entrypoints WXT (background, popup) и глобальные стили — только запуск
  pages/      экраны: popup, options
  modules/    servers — хранение и выбор серверов
              routing — правила браузера и ядра, действие по умолчанию, кнопка «этот сайт»
              connection — хелпер, ядро, настройки прокси браузера (фон) и панель статуса
  common/     i18n (строки интерфейса), storage (реактивная обёртка над WXT storage)
```

Вариация проекта:

- уровни `app / pages / modules / common`; entrypoints WXT лежат в `app/entrypoints`;
- модули в kebab-case, доступ извне только через `index.ts`;
- в `common` нет index-файлов, импорт по прямому пути;
- межуровневые импорты через `@/`.

Состояние живёт в `storage.local`: popup и настройки пишут желаемое (`proxyEnabled`, выбранный
сервер, правила), фоновый сервис приводит к нему фактическое и пишет `connectionStatus`.
Изменение правил браузера меняет только PAC / `proxy.onRequest`; изменение сервера, правил ядра
или действия по умолчанию перезапускает ядро.

`tldts` нужна только попапу; в `wxt.config.ts` она помечена как модуль без побочных эффектов,
иначе её таблица суффиксов попадает в фоновый скрипт.
