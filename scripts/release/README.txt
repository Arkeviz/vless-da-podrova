vless-da-podrova {{VERSION}}
============================

Браузерное расширение, которое пускает трафик браузера через ваш собственный VLESS-сервер.
Для Windows 10/11 и браузеров Chrome, Edge, Яндекс Браузер, Firefox.
Ядро - sing-box {{SING_BOX_VERSION}} (лежит в архиве, в папке sing-box).

Что в архиве
------------
  install.cmd        установка хелпера и sing-box (двойной клик)
  uninstall.cmd      удаление
  extension\chrome   расширение для Chrome, Edge, Яндекс Браузера
  extension\firefox  расширение для Firefox (для проверки; постоянно - файл .xpi, если он есть рядом)
  helper\            нативный хелпер, который запускает sing-box
  sing-box\          ядро
  install.ps1, uninstall.ps1, sing-box.json   то, что запускают .cmd-файлы


1. Установка хелпера и sing-box
-------------------------------
Распакуйте архив в любую папку и запустите install.cmd двойным щелчком.
Права администратора не нужны. Скрипт:

  - копирует хелпер, sing-box и расширения в %LOCALAPPDATA%\vless-da-podrova;
  - регистрирует хелпер для Chrome, Edge, Яндекс Браузера и Firefox (раздел HKCU реестра).

Если sing-box в архиве нет или он повреждён, скрипт скачает его с GitHub и сверит SHA256
с закреплённым в sing-box.json. Без интернета: скачайте sing-box-{{SING_BOX_VERSION}}-windows-amd64.zip
вручную и запустите в PowerShell:  .\install.ps1 -SingBoxZip путь\к\архиву.zip

После установки ПЕРЕЗАПУСТИТЕ браузер. Распакованную папку архива можно удалить -
всё нужное скопировано в %LOCALAPPDATA%\vless-da-podrova.


2. Установка расширения
-----------------------
Chrome / Edge / Яндекс Браузер
  1. Откройте chrome://extensions (Edge: edge://extensions, Яндекс: browser://extensions).
  2. Включите «Режим разработчика».
  3. «Загрузить распакованное расширение» и выберите папку
       %LOCALAPPDATA%\vless-da-podrova\extension\chrome
     (скопируйте путь в адресную строку окна выбора папки). Эту папку не удаляйте.

Firefox
  - Если в extension\ есть файл vless-da-podrova-{{VERSION}}-firefox.xpi - перетащите его в окно
    Firefox и нажмите «Добавить». Расширение подписано и остаётся навсегда.
  - Если .xpi нет - временная установка: about:debugging -> «Этот Firefox» ->
    «Загрузить временное дополнение» -> файл manifest.json из
       %LOCALAPPDATA%\vless-da-podrova\extension\firefox
    Такое дополнение пропадает после перезапуска Firefox.
  - В приватных окнах расширение работает, только если включить на его странице
    «Запускать в приватных окнах».


3. Начало работы
----------------
Откройте окно расширения, вставьте ссылку vless:// (или адрес подписки) и нажмите «Включить».
Правила «через прокси / напрямую», режим «Вкладка через прокси» и защита от утечек -
в настройках расширения.


4. Обновление
-------------
Распакуйте новый архив, запустите install.cmd (прокси перед этим выключите), затем обновите
расширение: в chrome://extensions нажмите «Обновить» у расширения, в Firefox установите новый .xpi.
Настройки, серверы и подписки сохраняются.


5. Удаление
-----------
Запустите uninstall.cmd (выключите прокси и закройте браузеры), затем удалите расширение
в самом браузере.


Если что-то не работает
-----------------------
  - «Хелпер не установлен» - запустите install.cmd и перезапустите браузер.
  - Windows SmartScreen или антивирус ругается на helper\vless-da-podrova-helper.exe - программа
    не подписана сертификатом; файл собран из открытых исходников проекта. Разрешите запуск
    или добавьте папку %LOCALAPPDATA%\vless-da-podrova в исключения.
  - Подробнее - в README проекта на GitHub.
